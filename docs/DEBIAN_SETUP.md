# Первичная установка на Debian

Этот документ нужен администратору перед включением автоматического обновления.
Исходники берутся из [основного GitHub-репозитория](https://github.com/leonidzaharov/Kvantol1nGo),
ветка `production`. Gitea служит для отдельной проверки ветки `test`.

Если сайт уже работает на сервере, сначала проверьте фактические пути, службу,
базу и настройки. Повторно восстанавливать данные или создавать базу не нужно.
После сверки переходите к [настройке обновления](../deploy/linux/AUTO-DEPLOY.md).

## Что необходимо для первого запуска

- Debian с Node.js 24, npm, PostgreSQL 17 и HTTPS-прокси (например, nginx).
- Отдельная роль и база PostgreSQL для приложения, без доступа к базе
  основного сайта техникума.
- Пользователь службы `quantorium`; исходники и сборка в
  `/opt/quantorium/app`.
- Постоянный каталог `/var/lib/quantorium/uploads` с правами на запись
  пользователю службы. Он не должен находиться внутри сменяемого релиза.
- Файл `/etc/quantorium.env` по
  [шаблону](../deploy/linux/environment.example). В нём адрес своей базы,
  `AUTH_SECRET`, публичный HTTPS-адрес, `STORAGE_DRIVER=local` и
  `UPLOADS_DIR=/var/lib/quantorium/uploads`. Права файла — только для
  администратора и службы. Секреты не помещаются в Git.

Настройки запуска находятся в
[`deploy/linux/quantorium.service`](../deploy/linux/quantorium.service), пример
прокси — в [`nginx-location.conf`](../deploy/linux/nginx-location.conf).
Перед использованием проверьте путь к Node, порт 3100, имя пользователя службы
и существующую конфигурацию сервера.

## Код и данные — разные части

GitHub содержит программу, миграции PostgreSQL и встроенные изображения.
Записи учеников, уроки, прогресс и картинки, загруженные через редактор,
хранятся отдельно. Их переносите из ранее подготовленного миграционного архива
после проверки даты снимка; архив от 9 сентября может быть устаревшим. Для
восстановления используйте новую выделенную базу, а не базу сайта техникума.
Не запускайте `prisma migrate reset`, `prisma db push` или `seed` на рабочей
базе.

Для нового развёртывания порядок такой: подготовить базу и каталог uploads,
заполнить `/etc/quantorium.env`, установить зависимости через `npm ci`,
выполнить `prisma generate`, применить миграции через
`prisma migrate deploy`, восстановить данные и файлы из согласованного архива,
собрать приложение через `npm run build`, запустить службу и настроить HTTPS.
Восстановление должно выполняться по инструкции из самого миграционного
архива, с проверкой целевой базы и количества записей.

Перед включением автоматических обновлений проверьте:

1. `curl -fsS http://127.0.0.1:3100/api/health` возвращает HTTP 200 и
   показывает доступность базы.
2. Наставник входит, видит группы и уроки; ученик входит по прежнему PIN.
3. Старая и новая картинки уроков открываются после перезапуска службы.
4. Сайт техникума и его база не затронуты.

Затем настройте [автоматическое обновление с GitHub](../deploy/linux/AUTO-DEPLOY.md).
Оно устанавливает только новые версии кода; база и uploads сохраняются отдельно.
