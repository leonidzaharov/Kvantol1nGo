# Локальная проверка обновлений

Обычный запуск из папки проекта в Git Bash:

```sh
npm run dev
```

Откройте http://localhost:3000/mentor. Имя и PIN локального наставника
сохранены в `.local/mentor.json`. Для остановки сайта нажмите Ctrl+C.
Если порт уже занят этим проектом, используйте открытый сайт или остановите
прежний терминал. Второй сервер запускать не нужно.

## Что подготовлено на этом компьютере

- PostgreSQL 17.10 слушает только `127.0.0.1:55432`.
- База называется `kvantolingo_local`; в ней один наставник и курсы
  Scratch и Python. Для проверки в Python через админку импортирован урок
  «Циклы: запусти академию» с рабочего стола. Настоящих учеников здесь нет.
- Файлы PostgreSQL и база находятся в `%LOCALAPPDATA%/KvantoLingo`.
  Путь без кириллицы нужен для совместимости Windows-версии PostgreSQL.
- Перед запуском сайта `predev` запускает базу, если она остановлена,
  и проверяет соединение. После Ctrl+C база может оставаться в фоне;
  повторный запуск использует её же. Данные между запусками сохраняются.
- `.env` содержит только локальные подключения и новый локальный секрет.
  `DATABASE_URL` и `DIRECT_URL` ведут в одну базу, поэтому приложение,
  миграции и служебные команды используют одно окружение.
- `uploads/` хранит изображения, импортированные через локальную админку.
- `.env`, `.local/`, база и загруженные изображения не входят в Git.

Готовые уроки остаются в отдельных папках на рабочем столе.
Для проверки редактора импортируйте MD/JSON и изображения через админку.
Локальное сохранение не публикует материал на рабочем сайте.

## Проверка перед выпуском

```sh
npm run lint
npm test
npx tsc --noEmit
npm run build
```

Остановите `npm run dev` перед production-сборкой: оба режима используют `.next`.
После проверки снова запустите `npm run dev`.
Интеграционные и браузерные тесты создают собственные временные схемы
в локальной базе. Для обычного просмотра страниц они не нужны.

## Границы локального запуска

`npm run dev` отклоняет удалённые адреса базы и несовпадение базы приложения
с базой миграций. Эти проверки относятся к разработке. `npm run build`,
`npm run start`, конфигурация Debian и порядок выпуска не изменены.
Публикация на GitHub в рамках этой настройки не выполнялась.

На другом компьютере можно использовать установленный PostgreSQL и свою
локальную базу. Укажите локальные `DATABASE_URL` и `DIRECT_URL`, `AUTH_SECRET`,
`AUTH_URL=http://localhost:3000`, `APP_URL=http://localhost:3000`,
`AUTH_TRUST_HOST=true`, `STORAGE_DRIVER=local` и абсолютный `UPLOADS_DIR`.
Переменные `LOCAL_POSTGRES_BIN` и `LOCAL_POSTGRES_DATA` нужны только для
автоматического запуска переносимой базы на этой машине.
Настройки CLI читаются из `.env`; не создавайте противоречащий ему `.env.local`.

Переносимые бинарные файлы получены из
[@embedded-postgres/windows-x64](https://github.com/leinelissen/embedded-postgres)
версии `17.10.0-beta.17`. Это локальный инструмент; в зависимости приложения
и в поставку Debian он не добавлен.
