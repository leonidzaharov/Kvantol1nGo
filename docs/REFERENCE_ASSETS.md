# Референсные ассеты

Локальный каталог `assets ux/` содержит пять Rive-файлов с названиями,
указывающими на Duolingo. Их происхождение и лицензия в репозитории не
зафиксированы.

Решение:

- каталог исключён из Git;
- файлы не копируются в `public/` и не загружаются в production;
- их можно использовать только как локальный визуальный референс;
- для продукта создаются собственные иллюстрации либо используются материалы с
  подтверждённой лицензией;
- у каждого будущего внешнего ассета должны быть источник, автор, лицензия и
  дата получения.
