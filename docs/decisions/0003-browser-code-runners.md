# ADR 0003: выполнение учебного кода в браузере

- Статус: принято
- Дата: 9 июля 2026

## Контекст

Ученикам нужно выполнять Python и JavaScript. Запуск непроверенного кода на
сервере потребовал бы отдельной sandbox-инфраструктуры и создал бы риск для
приложения и данных.

## Решение

Python выполняется через Pyodide, JavaScript — в отдельном Web Worker. Сервер
передаёт условие и ожидаемый результат, но не исполняет ученический код.
Runner ограничивает время и нормализует вывод перед сравнением.

## Последствия

Сервер не несёт стоимость и риск выполнения кода. Возможности заданий ограничены
браузерной средой, а первая загрузка Python зависит от размера Pyodide.
