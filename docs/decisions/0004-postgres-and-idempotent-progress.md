# ADR 0004: PostgreSQL и идемпотентный прогресс

- Статус: принято
- Дата: 30 июня 2026

## Контекст

SQLite не подходил для serverless-развёртывания и совместной работы. Повторные
запросы завершения урока не должны многократно начислять XP и монеты.

## Решение

Хранить данные в PostgreSQL через Prisma. Прогресс уникален по паре
`(userId, lessonId)`. Завершение урока и награды обрабатываются транзакционно,
проверяя предыдущее состояние.

## Последствия

Платформа поддерживает конкурентные запросы и повторную доставку действий.
Изменения схемы требуют миграций, резервных копий и проверки на PostgreSQL.
