# ADR 0001: модульный монолит на Next.js

- Статус: принято
- Дата: 23 июня 2026

## Контекст

Платформе нужны страницы ученика, административный интерфейс, авторизация,
мутации и доступ к одной базе. Команда небольшая, отдельные сервисы увеличили бы
стоимость разработки и эксплуатации.

## Решение

Использовать один Next.js App Router проект. Чтение данных выполняют Server
Components, мутации интерфейса — Server Actions, внешние HTTP-входы — Route
Handlers. Бизнес-правила остаются в `src/lib`, а не в JSX.

## Последствия

Развёртывание и транзакции остаются простыми. Границы модулей нужно поддерживать
структурой кода и тестами, поскольку отдельные сервисы их не обеспечивают.
