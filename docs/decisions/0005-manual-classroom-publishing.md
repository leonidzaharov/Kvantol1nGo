# ADR 0005: ручная публикация для очного занятия

- Статус: принято
- Дата: 24 июля 2026

## Контекст

Платформа используется как рабочая тетрадь на очном занятии. Наставник открывает
материал в нужный момент, ориентируясь на темп конкретной группы. Расписание и
жёсткие prerequisites мешали бы этому процессу.

## Решение

Курс и урок имеют независимый ручной статус публикации. Курс явно назначается
группам; урок наследует эти группы или сужает аудиторию. Все опубликованные
уроки доступны без блокировки по порядку. Наставник может предварительно пройти
черновик без прогресса и наград.

## Последствия

Видимость полностью контролируется преподавателем во время занятия. Система не
открывает материалы автоматически и не заменяет педагогическое решение.
Прямые ссылки и Server Actions используют те же серверные правила доступа.
