# ADR 0002: PIN-аутентификация и серверные guards

- Статус: принято
- Дата: 8 июля 2026

## Контекст

Ученикам на занятии нужен быстрый вход без электронной почты. При этом короткий
PIN подвержен перебору, а административные права нельзя доверять данным клиента
или долгоживущему JWT.

## Решение

Ученик выбирает заранее созданный профиль и вводит 4-значный PIN. Наставник
входит через отдельную форму с PIN длиной 8–10 цифр. Неудачные попытки
ограничиваются по пользователю и окну времени. Server Actions получают текущего
пользователя только из сессии; `isAdmin` читается из БД при каждой защищённой
операции.

## Последствия

Вход удобен в классе, а снятие административных прав действует немедленно.
Короткий ученический PIN допустим только вместе с rate limit, короткой сессией и
контролируемым списком профилей.
