# ADR 0006: отдельные сессии для живого очного занятия

- Статус: принято
- Дата: 25 июля 2026

## Контекст

Постоянный прогресс урока хранит первое завершение, XP и награды. Он не отвечает
на вопрос наставника «что ребёнок делает прямо сейчас» и смешивает повторные
прохождения с прежними занятиями.

## Решение

Наставник явно запускает `ClassSession` для группы и урока. Текущая фаза,
позиция и агрегированные ошибки сохраняются в отдельных сессионных таблицах.
Дашборд читает защищённый снимок раз в три секунды. Исходный код, выбранные
ответы и полный журнал кликов не сохраняются.

## Последствия

- текущее занятие не смешивается с постоянными наградами и прошлым прогрессом;
- можно одновременно вести разные группы;
- объём данных ограничен состояниями и счётчиками;
- для работы дашборда наставник должен нажать «Начать занятие»;
- WebSocket-инфраструктура не нужна для размера обычного учебного класса.
