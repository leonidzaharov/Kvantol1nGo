# Урок 08. Циклы: миссия «Запусти академию»

Готовый контент для KvantoLingo: 10 экранов теории, 15 обязательных вопросов, 3 бонусных задания и 8 иллюстраций из предоставленного комплекта.

Предварительные знания: print, переменные, строки, сравнения и if. Списки повторяются в начале. Ориентир: 45-60 минут; бонусы по желанию.

## Файлы

- `theory.md`: теория для поля Markdown в редакторе.
- `questions.json`: импорт обязательных и бонусных вопросов через кнопку импорта JSON.
- `lesson.json`: полный контент в формате LessonContentSchema. Это резервная сборка для проверки, а не отдельная команда публикации.
- `public/lessons/python/08-loops/`: иллюстрации. В Markdown используются адреса `/lessons/python/08-loops/*.png`.

Иллюстрации взяты из пользовательской папки «Урок_08_Циклы/images»; пустые таблички заполнены подписями и значениями из урока. Задания переработаны по сценарию учителя «Урок_08_Циклы_и_списки». Реальные данные учеников не используются.

## Добавление через админку

1. После успешного CI и обновления рабочего сайта проверить загрузку `/lessons/python/08-loops/t01.png`.
2. В разделе уроков создать урок в существующем курсе Python. Название: `Циклы: миссия «Запусти академию»`. Поставить после урока об условиях. Рекомендованные награды: 30 XP, 5 монет.
3. Переключить редактор теории в Markdown и вставить весь `theory.md`. Можно использовать имеющийся импорт из папки: абсолютные ссылки на картинки уже готовы и повторной загрузки не требуют.
4. Один раз импортировать `questions.json`: должно появиться 15 основных и 3 бонусных вопроса. Повторный импорт добавляет дубликаты, а не заменяет вопросы.
5. Сохранить, открыть предпросмотр ученика, проверить шаги и картинки. Назначить нужную группу и опубликовать в момент занятия.

Push доставляет файлы и картинки, но сам не создаёт урок в рабочей базе. Seed для установки этого урока не запускать.

## Как вести практику

Порядок: предсказание результата, короткое объяснение, самостоятельный запуск. Основные задания чередуют выбор ответа, числовой ответ и код. У ребёнка есть стартовый код, а эталонные решения остаются в административном контенте.

Встроенный проверяющий механизм сравнивает вывод, но не доказывает использование for, while или append. Наставник проверяет алгоритм по коду ученика. В отличие от исходного отдельного квеста здесь нет ограничения в 200 повторов или проверки конкретной синтаксической конструкции. Намеренно бесконечные программы в урок не включены.

Вопрос 1 проверяет факт об игровом цикле, вопрос 3 - пустую последовательность, вопросы 6-7 - границы range, вопросы 9-11 - предварительную проверку условия while. Бонусы: накопитель, максимум и фильтр.
