# Циклы: миссия «Запусти академию»

Ты уже встречал циклы. Теперь научим робота выдавать пропуски, заряжаться и собирать отряд. Сначала предсказывай результат, потом проверяй себя в заданиях.

## 1. Зачем повторять команды

![Карточки учеников на стойке академии](/lessons/python/08-loops/t01.png)

Три ученика - три пропуска. А если придут тридцать? Вместо копирования команды попросим робота: **«Для каждого имени напечатай пропуск»**.

> [!важно] Факт: игры тоже повторяют действия
> Игровой цикл снова и снова читает нажатия, обновляет мир и рисует кадр. В учебном примере Pygame частоту ограничивают 60 кадрами в секунду. Это ограничение, а не обещание, что любой компьютер выдаст ровно 60 кадров.

**Предскажи:** изменится ли число строк в теле цикла, если учеников станет больше? Нет: меняется список, а правило остаётся тем же.

## 2. Список и один элемент

![Робот выбирает одну из трёх карточек](/lessons/python/08-loops/t03.png)

```python
names = ["Мира", "Тео", "Ян"]
print(len(names))
print(names[0])
```

Получим `3` и `Мира`. `len(names)` считает элементы, а `names[0]` берёт первый. Нумерация начинается с нуля.

**Проверь мысль:** заменим «Мира» на «Александра». Учеников всё ещё трое. Длина списка не изменилась, длина первого имени изменилась.

## 3. for: для каждого по очереди

![Одинаковое действие для карточек по очереди](/lessons/python/08-loops/t02.png)

```python
students = ["Мира", "Тео", "Ян"]
for student in students:
    print("Пропуск: " + student)
```

После заголовка ставим двоеточие. Строку внутри цикла сдвигаем вправо на **4 пробела**. Это тело цикла.

| Шаг | Значение student | Что напечатает робот |
| --- | --- | --- |
| 1 | Мира | Пропуск: Мира |
| 2 | Тео | Пропуск: Тео |
| 3 | Ян | Пропуск: Ян |

Имя `student` придумали мы. Можно назвать его `hero`, но тогда и в `print` нужно использовать `hero`.

> [!важно] Факт: пустой список - ноль повторений
> Цикл `for` по `[]` ни разу не выполнит тело. Роботу не нужна отдельная команда «сегодня никто не пришёл».

## 4. Отступ определяет, что повторится

![Предметы для рюкзака экспедиции](/lessons/python/08-loops/q02.png)

```python
items = ["карта", "вода"]
for item in items:
    print(item)
print("Готово")
```

Вывод:

```text
карта
вода
Готово
```

Последний `print` стоит без отступа, поэтому работает один раз после цикла.

**Мысленный эксперимент:** сдвинь его на 4 пробела. Теперь «Готово» появится после каждого предмета. В заданиях ты исправишь такую ошибку сам.

## 5. range: когда нужен счёт

![Поднос с ячейками для подготовки мест](/lessons/python/08-loops/q04.png)

Нужно подготовить места с номерами 1, 2 и 3:

```python
for number in range(1, 4):
    print(number)
```

`range(1, 4)` даёт 1, 2, 3. Правая граница **не входит**. А `range(3)` даёт 0, 1, 2: тоже три числа.

> [!важно] Факт: большой счётчик не обязан быть большим списком
> Объект `range` хранит правило последовательности, а не список всех её чисел. Поэтому для счёта не нужно заранее выписывать тысячу номеров.

**Предскажи:** для мест от 1 до 8 нужна правая граница 9. Число 9 уже за пределами нашего подноса.

## 6. Переменная может обновляться

![Робот с батареей на три сегмента](/lessons/python/08-loops/q05.png)

```python
energy = 0
energy = energy + 1
print(energy)
```

Получим `1`. Python сначала берёт старое значение справа, прибавляет единицу, затем сохраняет результат слева.

Это **присваивание**, а не математическое равенство. Следующее такое действие даст `2`.

**Пройди пальцем по шагам:** было 0 → стало 1 → стало 2 → стало 3. Так робот считает заряд.

## 7. while: проверяй перед каждым шагом

```python
energy = 0
while energy < 3:
    energy = energy + 1
print(energy)
```

| Перед проверкой | energy < 3 | Действие |
| --- | --- | --- |
| 0 | True | Увеличить до 1 |
| 1 | True | Увеличить до 2 |
| 2 | True | Увеличить до 3 |
| 3 | False | Выйти из цикла |

В конце напечатается только `3`: `print` стоит после цикла.

> [!важно] Факт: while может не начать работу
> Если заряд уже равен 3, условие сразу ложно. Тело не выполнится ни разу. Проверка происходит до действия.

**Осторожно:** если забыть увеличивать заряд, в этом примере условие останется истинным. Не запускай намеренно бесконечный цикл. В задании найдёшь безопасное исправление.

## 8. Каждый предмет можно проверить

```python
names = ["Лев", "Виктория", "Александра"]
for name in names:
    if len(name) > 8:
        print("Сократить")
    else:
        print("Влезает")
```

Цикл берёт имя, а `if` решает, поместится ли оно на бейдже. Получим: `Влезает`, `Влезает`, `Сократить`.

Отступы образуют лестницу: `for` на старте, `if` на 4 пробелах, его `print` на 8. `else` стоит на одном уровне с `if`.

**Проверь границу:** в «Виктория» ровно 8 букв. Условие `> 8` ложно; `>= 8` изменило бы результат.

## 9. Копилка: результат нескольких шагов

![Мешки сокровищ для общей копилки](/lessons/python/08-loops/q06.png)

```python
coins = [2, 5, 3, 1, 4]
total = 0
for coin in coins:
    total = total + coin
print(total)
```

Копилка меняется так: **0 → 2 → 7 → 10 → 11 → 15**. Ноль задаём до цикла, иначе каждый шаг начнётся с пустой копилки.

**Предскажи:** если убрать последнюю монету, получим 11. Именно так программа может собирать общий счёт из нескольких наград.

## 10. Секретный маршрут: чемпион и отряд

![Герои академии для отбора в отряд](/lessons/python/08-loops/q07.png)

Чтобы найти максимум, назначь первого героя чемпионом: `best = levels[0]`. Затем сравнивай каждый уровень с `best` и заменяй рекорд, если нашёл больше. Этот способ требует непустого списка.

Чтобы собрать отряд, создай новый список:

```python
squad = []
squad.append("Мира")
print(squad)
```

Вывод: `['Мира']`. Метод `append` добавляет один элемент в конец. В бонусе добавляй только имена, которые прошли условие.

**Твой маршрут практики:** предскажи → выбери объяснение → допиши код → запусти и сравни вывод. Обязательные задания проверят основу, а три задания со звёздочкой предложат собственную сборку алгоритма.
