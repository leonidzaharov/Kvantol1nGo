# Архив документации

Файлы в этом каталоге описывают этапы разработки и могут противоречить текущему
коду. Они сохранены как история решений, но не являются инструкциями.

Актуальная точка входа — корневой `README.md`.

- `PROGRESS-legacy.md` — подробный хронологический журнал ранних работ.
- `PRODUCTION_READINESS-legacy.md` — первый аудит production-готовности.
- `SECURITY_AND_MIGRATION_PLAN-legacy.md` — план миграции с SQLite на Postgres.
- `GUIDE-legacy.md` — руководство к старой архитектуре с удалёнными
  dashboard/shop/inventory.
- `DEVLOG-legacy.txt` — ручной журнал разработки.
